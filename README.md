# MathVision 本地端恢复与 RK 研究工作台

这是一个**私有、仅本地运行**的 TypeScript/React 工程。当前代码从 MathVision 冻结生产构建机械恢复；近期目标是得到忠实、可运行、可逐步维护的前端基线，长期目标是在这个交互外壳上构建 RK 数学研究工作台。

## 我们具体要做什么

最终产品要把数学研究组织成两张彼此关联但权威含义不同的图：

- **研究线程图**：每个节点是一个可继续、暂停、分叉和审计的研究线程，保存消息、上下文、工具调用、工件和执行记录。
- **数学事实图**：每个节点是 RK 管理的数学 Claim，明确区分候选、已验证、失效和外部阻塞；聊天或工具输出不能直接成为已验证事实。

产品采用本地优先方式：不依赖 MathVision 登录，不复制生产 Cookie、令牌或账号数据；通过明确适配器连接 RK、本地模型、Lean、Z3、Python、CAS 和枚举工具。

## 当前状态

- 本地预览可运行，登录主链已删除。
- 聊天、文件夹、Workspace Explorer 和个人资料写入浏览器本地存储。
- 严格 TypeScript 区域与 7 个大型恢复视图分开验收。
- 未实现的后端请求返回 HTTP 501，不会静默访问 MathVision。
- 当前仍是恢复基线，不是 RK 集成完成版，也不宣称找回上游原始源码。

## 快速开始

```powershell
npm install
npm run dev
```

访问 `http://127.0.0.1:4173/chats`。

完整验证：

```powershell
npm run verify
```

## 重要边界

- 恢复阶段保持原有功能、接口、文案、视觉和交互，不自行重设计；唯一主动删除的品牌工件是 Logo。
- `recovered/`、`reports/` 和恢复脚本属于来源链，不能为了代码好看而删除。
- 第三方和上游代码的许可状态尚未在本仓库内裁定；在完成许可审查前保持私有，不对外发布。
