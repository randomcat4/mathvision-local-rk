# 当前架构

状态：只描述当前代码，不描述尚未实现的 RK 目标架构。

## 概览

这是一个 Vite 驱动的 React 19 单页应用。入口先安装本地请求适配器，再加载恢复的生产主分包。严格类型化的源码、薄兼容层、冻结运行基线和 7 个大型恢复视图并存。

## 技术栈

| 层 | 技术 | 锁定版本 |
|---|---|---:|
| 语言 | TypeScript | 5.9.2 |
| UI | React / React DOM | 19.2.5 |
| 构建 | Vite | 7.1.3 |
| HTTP | Axios | 1.19.0 |
| 数学排版 | KaTeX | 0.16.45 |
| PDF | pdfjs-dist | 4.10.38 |
| 图标 | lucide-react | 1.16.0 |
| 测试执行 | Node test + tsx | 4.20.5 |

版本以 `package-lock.json` 为准。

## 启动流程

1. `src/main.tsx` 加载原样式、KaTeX 和图样式。
2. `installLocalPreviewNetwork()` 安装请求拦截。
3. 动态加载恢复的生产主分包。
4. 主分包继续通过兼容导出与已提升源码协同运行。

本地适配器只拦截目标为 `https://app.mathvision.ai/api/v1` 且当前页面运行在本地主机的请求。支持的请求落到 `LocalRepository`；其余请求返回 501。

## 状态和持久化

- 界面偏好和本地实体保存在浏览器 `localStorage`。
- 使用固定本地身份，不建立 Keycloak 客户端。
- 不复制生产 Cookie、令牌或浏览器存储。
- 当前没有服务端数据库、真实模型运行队列或 RK 连接。

## 恢复边界

严格 TypeScript 模块和大型恢复视图采用不同验收口径：

- 严格区域执行完整类型检查。
- 7 个大型视图执行独立语法检查和生产构建。
- 冻结第三方或混合边界保留在运行基线中，直到可以证明替换不改变行为。

精确数字和最新验证结果以根目录 `RECOVERY_STATUS.md` 为准。

## 当前架构债务

- 主入口仍依赖大型恢复分包，不是完全组件化的源码入口。
- 7 个大型视图内部仍保留压缩变量名。
- 本地请求适配器通过全局 `fetch` 接缝工作，不是长期领域接口。
- localStorage 仓库只覆盖聊天、文件夹和个人资料等有限对象。
- Notebook、工作流图和消息数据模型尚未与统一的研究线程对象结合。
